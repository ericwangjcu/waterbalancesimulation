How the demonstration works — step by step

Two simulations are run side-by-side for the same 45-day period. Baseline and CLOVER have the same site, crop water demand, realised weather, irrigation system and available water. The experiment isolates one change: CLOVER is allowed to use the short-term rainfall forecast when deciding whether to irrigate now or wait.

Only one treatment difference:
short-term forecast used in the decision
1
Set the farm scenario Select Centre Pivot (CP) or Lateral Move (LM). This sets the physical irrigation assumptions, including minimum irrigation cycle, application capacity, efficiency and system configuration.
2
Set water availability For the drought scenario, both strategies receive the same finite allocation. For the non-limited benchmark, irrigation water is not capped. This lets us test two different value pathways.
3
Start each simulated day The crop uses water each day. The daily crop-water-demand value increases soil water deficit (SWD). Higher SWD means the soil profile is becoming drier.
4
Ask: is irrigation due? If SWD is below the selected trigger, neither strategy irrigates. If SWD reaches the trigger, the model checks whether the CP/LM minimum cycle has elapsed and whether allocation is still available.
5
Baseline makes its decision If irrigation is due, the system is cycle-ready and water is available, Baseline irrigates. It does not know that rain may arrive tomorrow or several days later.
6
CLOVER checks the forecast CLOVER searches the selected look-ahead period. A forecast only qualifies when both forecast rainfall ≥ the rain threshold and probability ≥ the probability threshold.
7
Irrigate now or delay If no forecast qualifies, CLOVER irrigates like Baseline. If a forecast qualifies, CLOVER delays irrigation — unless SWD has reached the forced-irrigation limit, set 20 mm drier than the trigger.
8
Apply irrigation, then actual rain Any irrigation chosen for that day reduces SWD. The same realised rainfall is then applied to both simulations. Rain that fills an existing soil-water deficit counts as effective rainfall; excess is treated as rain loss.
9
Track stress and crop response If SWD becomes very high, a water-stress index accumulates. The current demo converts accumulated stress into an illustrative cane-yield response. This is a proxy, not an APSIM result.
10
Repeat and compare The process repeats for all 45 days. We then compare effective rainfall, irrigation timing and volume, allocation use, water stress and the indicative yield response between Baseline and CLOVER.
Baseline decision at an irrigation window SWD ≥ trigger → CP/LM cycle ready → allocation available → irrigate now.
VS
CLOVER decision at the same irrigation window SWD ≥ trigger → cycle ready → allocation available → check forecast → irrigate now or delay for qualifying rain.
Example: SWD reaches 60 mm, so irrigation is due. The forecast says 25 mm of rain in the next 2 days at 80% probability. If the controls are set to 20 mm rainfall, 70% probability and a 3-day look-ahead, that forecast qualifies. Baseline irrigates now; CLOVER waits. If the rain occurs, CLOVER may receive more effective rainfall because its soil profile had more room to store it. If the forecast does not verify and the soil becomes too dry, the forced-irrigation rule prevents indefinite delay.
Limited water / drought pathway: both strategies have the same finite irrigation allocation. Better timing can increase effective rainfall and leave scarce irrigation available for later crop demand → less stress → potential TCH/TSH protection.
Non-limited benchmark pathway: irrigation water is always available. Better timing can allow rainfall to replace some irrigation → fewer/lower irrigation applications → reduced pumping and water cost while yield remains similar.
Why a slider sometimes appears to do nothing: rainfall and probability thresholds are decision gates. Changing 70% to 75%, for example, only changes the irrigation schedule if a forecast near that boundary occurs during a day when irrigation is actually due, the system is cycle-ready and water is available. Steve's initial modelling structure

What is held constant

Site, crop water demand, precision irrigation, scheduling, automation, weather and available irrigation water.

What changes

Baseline has no short-term forecast. CLOVER uses forecast rain amount × probability to modify irrigation timing.

Primary value under limited water

More effective rain can support greater crop water use and reduce water stress, potentially increasing TCH/TSH.

Primary value when water is non-limiting

More effective rain can lower irrigation demand and therefore reduce water and pumping cost while maintaining yield.
