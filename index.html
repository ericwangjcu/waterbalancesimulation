Level 1 — understand the basic CLOVER decision

Same farm. Same crop demand. Same weather. One difference: CLOVER can see the short-term forecast.

Start with Steve's Centre Pivot setup. The four equal-quarter IMUs are simulated independently for soil-water accounting so we can see which crop classes are becoming dry. Baseline irrigates when the SWD rule is met. CLOVER checks the rainfall forecast first and can wait.

Level 5 — full CLOVER farm decision

When several IMUs need irrigation and one pump cannot service them all, which IMU goes first?

This level keeps Steve's 11-IMU Mackay traveller geometry and irrigation capacity because one traveller/pump creates an intuitive capacity constraint. We then place the CLOVER decision layer on top as a future-state demonstration: decide whether irrigation should proceed or wait for forecast rain, then choose among eligible IMUs.

Priority rules are our simulation layer; Steve's workbook defines the farm/IMUs but does not prescribe this priority algorithm.
