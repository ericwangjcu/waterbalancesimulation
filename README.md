# CLOVER irrigation decision demonstrator

Interactive early-stage CLOVER demonstration for forecast-informed irrigation scheduling.

The demo compares a baseline SWD-triggered irrigation strategy with a forecast-informed strategy using synthetic rainfall forecasts, rainfall probability, realised rainfall and a simplified APSIM-style soil-water/yield proxy.

## Files

- `index.html` — interface
- `style.css` — site styling
- `app.js` — synthetic weather, irrigation decision logic and charts

> Demonstration only. The current simulation is not an APSIM model result. It is designed so the simplified proxy can later be replaced with APSIM/API outputs.
